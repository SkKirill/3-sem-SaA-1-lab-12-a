# Задача

Реализовать модуль для работы с линейным списком из целых чисел.  
a) без заглавного звена.  
В модуле должны быть реализованы следующие операции:
- инициализация
- проверка на пустоту
- добавление звена в начало списка
- добавление звена в конец списка
- добавление звена за заданным звеном
- удаление первого звена
- удаление последнего звена
- удаление звена следующего за заданным
- поиск заданного элемента в списке
- построение упорядоченного списка
- печать элементов списка

# Структура данных
## Устройство самого модуля:  

`TLinearList` и `TListNode`:  
  
`TLinearList` - это указатель на первый узел списка (тип `TListNode`).  
`TListNode` - это запись, представляющая отдельный узел списка. Она содержит поле `Data` для хранения данных и поле `Next` для указания на следующий узел.  

## Процедуры и функции:
- `InitList`: Инициализирует пустой список, устанавливая List равным nil.
- `IsEmpty`: Возвращает True, если список пуст (List равен nil).
- `AddFirst`: Добавляет новый узел в начало списка.
- `AddLast`: Добавляет новый узел в конец списка.
- `AddAfter`: Добавляет новый узел после заданного узла.
- `DeleteFirst`: Удаляет первый узел из списка.
- `DeleteLast`: Удаляет последний узел из списка.
- `DeleteAfter`: Удаляет узел, следующий за заданным.
- `Search`: Ищет заданный элемент в списке и возвращает указатель на него, если он найден, иначе nil.
- `SortList`: Сортирует список по возрастанию.
- `PrintList`: Выводит элементы списка на консоль.

# Условие:
> [!WARNING]
> “Без заглавного звена” в контексте реализации линейного списка на Delphi 7 означает, 
что список не имеет отдельного звена (узла), которое служит “головой” списка.

В традиционных реализациях линейных списков с заглавным звеном используется отдельная переменная, 
которая удерживает указатель на первый элемент списка. Эта переменная называется “голова” (head) списка.
Все операции с списком (добавление, удаление, поиск) происходят относительно этой “головы”.

Без заглавного звена это означает, что у вас нет отдельной переменной “голова”, и указатель на
первый элемент списка хранится в самом первом элементе списка. (В данном случае это будет элемент, который
передается как параметр в методы и хранить голова будет вне модуля.)

## Пример:

### С заглавным звеном:

```Pascal
type
  TListNode = record
    Data: Integer;
    Next: TListNode;
  end;

  TLinearList = ^TListNode; // Указатель на голову списка

var
  Head: TLinearList; // Переменная "голова"
```

### Без заглавного звена:

```Pascal
type
  TListNode = record
    Data: Integer;
    Next: TListNode;
  end;

  TLinearList = TListNode; // Тип списка - это тип узла 
```
